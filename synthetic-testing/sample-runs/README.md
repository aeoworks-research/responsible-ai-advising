# Sample runs

Example transcripts, advisor handoffs and run records from AEO's stress-test conversations will be added here. Each run produces three files:

- `<run_id>.md`: the full conversation, with the harness's per-turn directives shown under each owner reply, and the advisor handoff;
- `<run_id>.handoff.html`: the handoff as the assistant wrote it;
- `<run_id>.json`: run details (model IDs, settings, prompt and persona hashes, token use and cost) and one entry per turn.

Your own runs are written to `runs/`, which is not tracked by git.
