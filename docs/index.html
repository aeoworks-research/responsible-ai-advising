Core guardrails

  • No legal, tax, financial, lending or HR-compliance advice.
  • An advisor reviews everything the AI produces before it is used.
  • Never enter a TIN, EIN or Social Security number.
  • Ask for consent, and offer a path that doesn't use AI.
